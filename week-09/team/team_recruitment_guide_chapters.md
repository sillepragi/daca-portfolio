# Recruitment guide chapters 1 and 2: How to Assess data analyst's technical skills and portfolio

**Team:** Marketing analytics team

---

## 1. OVERVIEW
This chapter discusses how to assess the technical skills and portfolio of a **Data Analyst** during the recruitment process. In addition to checking theoretical knowledge, it is critical to analyze the candidate’s previous projects, as they demonstrate **practical experience**, the ability to solve real business problems, and the quality of the documentation of the work.

## 2. EVALUATION CRITERIA

### **Technical Skills**
* **SQL query writing:** Ability to use `SELECT`, `JOIN`, `GROUP BY` and more complex `CTE` solutions to retrieve data.
* **Using Python and Pandas:** Ability to manipulate data, perform calculations and automate processes.
* **Excel or Power BI proficiency:** Ability to create interactive dashboards and visuals that answer business questions.
* **Data cleaning and visualization:** Ability to transform "data chaos" into reliable and readable information.

### **Portfolio assessment**
* **GitHub content:** Does the repository contain **real-world projects** (e.g. RFM analysis, sales trends), not just theoretical exercises.
* **Quality vs. quantity:** The systematicity and completion of projects are assessed, not just the number of files.
* **Readability and documentation:** Is the code commented and does the `README.md` clearly explain the purpose of the work.
* **Business interpretation:** Can the candidate explain the impact of the data on the company's growth (e.g., "what should we do with this information?").

### **Problem solving**
* **Explanation of thinking:** The candidate is able to explain their logic behind technical choices.
* **Logical approach:** Solving tasks in a structured way (e.g., following an ETL process).
* **Data error detection:** Ability to identify anomalies, duplicates, or NULL values.

## 3. SPECIFIC EXAMPLES (UrbanStyle context)

**Strong candidate for UrbanStyle:**
* Writes an SQL query that finds **best-selling products** and extracts their share of total sales.
* Uses Python to perform **RFM customer segmentation**, identifying VIP customers and churn risk.
* Creates a dashboard that visualizes **sales trends** and helps prepare meeting for an investor meeting.
* Has projects on GitHub that show **the actual data cleaning process** (audit log).
* Can collaborate with other parties (e.g. Anna Metsaga from marketing) to find trends in data to make better business decisions.

**Sample projects that the candidate could show:**
* **Sales analysis project:** Detailed view by product category and channel.
* **Customer behavior analysis:** Comparison of registered vs. purchased customers (LEFT JOIN example).
* **Power BI dashboard:** Strategic overview for investors.
* **Documented GitHub repository:** Repository with a clear structure and `README` files.

## 4. 3 KEY ADVICE FOR MANAGERS

1. **Use practical tasks in the interview:** Ask the candidate to write a live SQL query or explain pandas code to make sure of real skills.
2. **Evaluate systematicity, not quantity:** One thoroughly documented and commercially meaningful project is more valuable than ten half-baked scripts.
3. **Ask to explain the project:** Have the candidate talk about a project using the **STAR method** (Situation, Task, Activity, Result) to test both technical acumen and self-expression.

## 5. A SURPRISING DISCOVERY
Sometimes **one well-done practical project**, where the candidate has been able to create clear business value from data chaos, demonstrates their skills and potential much better than a long CV or a large number of theoretical certifications.
