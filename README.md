# Data Analytics Portfolio

This repository showcases my projects and learning journey from the Data Analyst Career Accelerator (DACA): A Hands-On Mentorship Program.

## 👤 About me
I am a **Junior Data Analyst** with experience in data collection, validation, reporting and working with information systems.

Throughout my previous roles, I worked with data on a daily basis — collecting and validating information, ensuring data quality, identifying patterns and using data to support environmental decisions. All of this sparked my interest in developing a deeper understanding of data analytics and its potential to support decision-making.

To develop my technical skills, I completed the **Data Analyst Career Accelerator** program — an intensive 11-week training focused on developing practical data analytics skills.

During the program, I learned how to:
- Query and manage data using **SQL** and **PostgreSQL**
- Clean, transform and analyze data with **Python** and **Pandas**
- Create meaningful visualizations and dashboards using **Power BI**

I am excited to continue growing in the analytics field and am currently looking for opportunities where I can combine my existing experience with my technical skills to help turn data into valuable business insights.

## 🎯 Goal
- Building a strong foundation in data analytics  
- Applying SQL, Python, and Power BI in real-world scenarios  
- Working with end-to-end analytical workflows and business cases  
- Developing a portfolio that demonstrates practical analytical skills  

## 🛠️ Tech stack
- **Databases:** PostgreSQL (via Supabase)
- **Languages:** SQL, Python (Pandas, NumPy)
- **Visualization:** Power BI
- **Tools:** Git, GitHub, VS Code
